# FoodReels 🍔🎬

A short-video food discovery and ordering platform. Think TikTok meets Zomato.

## Features

### For Customers
- 📱 Scroll through engaging food reels
- ❤️ Like, comment, and save reels
- 🏪 Follow your favorite restaurants
- 🛒 Order food directly from reels
- 📍 Manage delivery addresses
- 📊 Personalized feed based on preferences

### For Restaurant Owners
- 🎥 Upload food reels with menu items
- 📈 View analytics (views, likes, orders, conversion)
- 🍽️ Manage menu items
- 📦 Handle incoming orders

## Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS, Zustand
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL 15
- **Cache:** Redis 7
- **Infrastructure:** Docker, Nginx

## Quick Start

### Prerequisites
- Node.js 20+
- Docker & Docker Compose
- PostgreSQL 15+ (or use Docker)
- Redis 7+ (or use Docker)
